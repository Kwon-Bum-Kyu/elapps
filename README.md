# Elapps

Elapps는 00:00부터 세는 데스크톱 집중 타이머입니다. 사용할 앱을 고른 뒤 끝낼 때까지 집중 시간을 쌓습니다.

이 레포는 설치 파일 배포 전용입니다. 설치 파일은 [Releases](https://github.com/Kwon-Bum-Kyu/elapps/releases/latest)에서 내려받습니다.

| OS | 파일 | 지원 범위 |
| --- | --- | --- |
| macOS | `Elapps-<버전>-universal.dmg` | macOS 12 이상, Intel·Apple Silicon |
| Windows | `Elapps-Setup-<버전>.exe` | Windows 10 이상, x64 |
